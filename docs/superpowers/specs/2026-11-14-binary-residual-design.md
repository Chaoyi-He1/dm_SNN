# 二值(0/1)残差流:设计

日期 2026-11-14。上一步是三值残差流(`2026-10-25-ternary-residual-design.md`,结果在 `step2-toy-demo/results/improve/README.md` 的"三值残差流"一节)。

## 要回答的问题

把层与层之间、GDN 到前馈之间的残差流从三值(−1 / 0 / +1)改成二值(0 / 1,只有"有脉冲 / 没脉冲",没有负号),
**要付出什么代价才能让模型的性能和 DNN 版(浮点 A0)差不多**。用户确认二值指 0 / 1,不是 −1 / +1。

"差不多"的判据(我定的,结果里三项都报,读者可以换判据):

1. 切片 token 准确率在 A0(0.842)的 1 个百分点以内,即 ≥ 0.832;
2. 5 道 demo 题全对,且训练最后 10 次评估里至少 5 次全对;
3. 整句贪心背对率(3277 句,A0 是 99.97%)单独报告,不设硬门槛。

参照:实值残差的脉冲模型 T=2 是 0.825–0.830 / 整句 0.834–0.887,T=4 是 0.832–0.836 / 0.912–0.946,T=8 是 0.836 / 0.965;
三值残差(sat)T=2 是 0.805–0.814 / 0.677–0.723,T=1 是 0.624–0.626 / 0.134–0.145。

## 模型

新类,不改已有的模型代码(`SpikingLM`、`TernaryResidualLM` 及其块都不动):

- `snn_spec/binary_residual.py`:`BinaryQuantizer`、`BinaryMerge`、`BinaryResidualBlock`
- `toy_demo/binary_residual.py`:`BinaryResidualLM`、阈值标定

数据通路与三值残差相同:`r0 = Q_emb(emb(tok))`,每块 `h' = M(r, y1)`、`r_out = M(h', y2)`,输出头直接读最后一层的 `r_out`。
差别只在残差流的取值与合并规则:

- 残差流 r ∈ {0, 1}(每 token 最多 T 个脉冲时是 {0, 1/T, …, 1}),一根线,没有负脉冲。
- `Q_emb` 是无符号量化器:嵌入值 ≥ 阈值得 1,否则 0(负的一半信息在这里丢掉,靠微调让嵌入表适应)。
- 子块内部的脉冲点不变:q、g 二值,k、v、o_spk、u 三值。"二值"只约束残差流,即层的输入、输出和 GDN → 前馈的那一段。
- 合并 M 两种(我定的,和三值残差那次一样两种都试):
  - **sr(置位 / 复位)**:子块输出 y 仍是三值,只在块内走一小段;y 的正脉冲把 r 置 1,负脉冲把 r 清 0,y = 0 时保持:
    `r' = clamp(r + y, 0, 1)`。T = 1 时就是 SR 锁存器 `r' = (r OR y⁺) AND NOT y⁻`;T > 1 时是每通道一个 0…T 的饱和计数。
    阈值固定 1.0,不用标定。
  - **xor(翻转)**:子块输出 y 也改成无符号(输出神经元换成二值 LIF),`r' = |r − y|`。T = 1 时是异或门(y = 1 把 r 翻转);
    T > 1 时等于把两路对齐的脉冲串逐子时隙异或,剩 |c_r − c_y| 个脉冲。没有比较器。
  两种规则在 y = 0 时都有 r' = r,残差的恒等通路保留(三值残差那次 and 规则输就输在这里)。

## 代价的几个旋钮

1. **每 token 的脉冲数 T**(时间和脉冲数):T ∈ {1, 2, 4, 8}。无符号的 T 级有 T+1 个电平,三值的 T 级有 2T+1 个,
   所以二值 T = 2k 与三值 T = k 电平数相同;对照需要三值残差在 T = 4 的结果(补跑一条)。
2. **宽度 d**(连线数和阵列面积):d = 256(已有加宽的 A0,0.840)对 d = 128。三值一个通道要两根线(或三电平),
   二值一根,所以"二值 d = 256"和"三值 d = 128"的层间连线数相同。
3. 两个不用训练就成立的上界(只作为读数时的参照,不单独跑):
   - 双轨:把三值 r 拆成 (r⁺, r⁻) 两个 0/1 通道,读它的矩阵取 [W, −W],与三值残差逐位相同。即二值流用 2 倍连线可以精确复现三值流。
   - 偏置码:`r_b = (r_t + 1) / 2` 用 T' = 2T 的无符号电平精确表示三值 T 级,代价是"0"也要发脉冲(稀疏性没了)且读出要一个常数偏置。

## 运行

配方与三值残差相同:`chain` = iscan(fq ∈ {0.5, 0.75, 0.9})→ A1(leak 0,12000 步上限,lr 3e-3)→ bscan(LIF 阈值倍数)→ C(leak 0.9)。
只用 GPU 1。

- 第一批(种子 0,d = 128):sr × T ∈ {1, 2, 4, 8},xor × T ∈ {1, 2},三值 sat T = 4(对照)。
- 第二批:胜出的规则在 d = 256 上跑 T ∈ {1, 2, 4};离判据最近的配置补种子 1、2。
- 每个 C 做整句背对率(贪心与 K = 4);达到判据或最接近的配置用 `energy_estimate.py` 估能耗。
