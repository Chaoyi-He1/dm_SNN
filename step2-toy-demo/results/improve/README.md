# 三个改进方向的实验(2026-10-15 至 16)

起点是转换扫描交付的 C(`../conversion-sweep/CL2_l1_lif225_lr3e3_12k`):切片 token 准确率 0.752,demo 1/5。它的补全错误是"岔路口选错一个词,再接上别的句子里背过的片段"。这里试了三个方向:训练更久、放宽每 token 的信息量(每 token 多个脉冲,或加宽模型)、换解码方式(束搜索)。本文的数字与结论经独立核对(数字与 result.json、history.jsonl、beam/*.json、profile_final.json 一致;措辞按核对意见修正)。

## 评估口径

- **token 准确率**:切片上 teacher forcing 的 top-1,与计划的统一评估函数相同。浮点 A0 是 0.842,加宽浮点 A0(d=256)是 0.840,这是这份语料的上限(句首几个词本来就不确定)。
- **demo**:计划第 3 节的 5 句贪心补全。**最后 10 次 5/5**衡量它稳不稳:训练中每 100 步评估一次,数最后 10 次里有几次 5 句全对。
- **整句背对率**:3277 句前 5 个 token 在切片里只出现一次的句子,从这 5 个 token 出发生成,输出必须逐 token 等于原句剩余部分。比 5 句 demo 稳得多。`experiments/beam_eval.py`。
- **每 token 脉冲**:整个模型(21 个脉冲点:每块 10 个 × 2 块 + q_out;原宽度 3200 个神经元,加宽 6400 个)每个 token 发出的脉冲总数,512 句平均。**W2 事件**:SwiGLU 门 p = g·u 送进 W2 的事件数,T > 1 时是两个脉冲计数之积(见下)。`experiments/model_profile.py`。
- 训练设置沿用转换扫描的采纳配方,不是计划第 5 节的原设定:A1 lr 3e-3、余弦、上限 12000 步(计划 2000);C lr 3e-3、上限 12000 步(计划 1e-3、1500 步);停止规则不变(5 句全对且 500 步内提升 < 0.1 个百分点)。
- 除 T=2、T=4 做了种子 0/1/2 外,其余运行都是种子 0。

## 方向 1:训练更久

| 运行 | A1 | C | C demo | 最后 10 次 5/5 | 整句(贪心 / 束搜索) |
|---|---|---|---|---|---|
| 已有基线:A1 12k → C 12k | 0.740 | 0.752 | 1/5 | 0 | 0.397 / 0.578 |
| 在基线 C 上续训(lr 1e-3,6500 步收敛) | 0.740 | 0.757 | 5/5 | 1 | 0.413 / 0.572 |
| A1 12k → C 24k(20400 步收敛) | 0.740 | 0.778 | 5/5 | 1 | 0.513 / 0.666 |
| A1 24k → C 24k(跑满) | 0.782 | 0.764 | 3/5 | 0 | 0.441 / 0.616 |

- 多训练让 C 的 token 准确率多 0.5–2.6 个百分点(续训 +0.5;A1 12k → C 24k +2.6;A1 24k → C 24k +1.2)。A1 从 12000 步加到 24000 步是 +4.2,但从它出发的 C 反而比从 12000 步 A1 出发的低(0.764 vs 0.778,单种子)。整句背对率涨得多一些:贪心 0.397 → 0.513,束搜索 0.578 → 0.666。
- 两个"5/5"都是停止规则碰上的单次评估:最后 10 次只有 1 次 5/5,其余在 0–4 之间跳。续训那次在第 2800 步还出现过一次 5/5(65 个评估点里共 2 次);A1 12k → C 24k 那次的 204 个评估点里只有最后一次是 5/5。
- 结论:在每 token 1 个脉冲下,训练预算不是主要瓶颈,但仍有影响。两个 24k 运行停在步数上限,余弦末段仍在涨,所以不能说训练预算已经不限制精度;能说的是,预算翻倍的收益(C +2.6,整句 +11.6 个百分点)远小于 T=2(C 0.825,整句 0.834)。

## 方向 2:放宽每 token 的信息量

### 每 token 多个脉冲(T > 1)

实现见 `experiments/multilevel.py`:电荷注入式 IF,每 token 内 T 个子步不泄漏,脉冲数 c = min(floor(U·T/θ), T),输出 s = c/T,软复位减 θ·s;三值点正负对称;θ 仍是满量程。T = 1 与原实现逐位相同(已测)。代理梯度是 T 个 arctan 阶跃的平均,总积分与 T = 1 相同。

转换时两个超参数要随 T 重新定(都是只做前向的扫描,结果在 `iscan_T*.json`、`*_bscan.json`):

| T | 扫过的分位数 | 选用的分位数 | A1 初始化准确率 | C 前的 LIF 阈值倍数 |
|---|---|---|---|---|
| 1 | 0.5、0.75 | 0.5(沿用扫描) | 0.123 | 2.25 |
| 2 | 0.5–0.98 | 0.75 | 0.242 | 1.5 |
| 4 | 0.5–0.98 | 0.9 | 0.312 | 1 |
| 8 | 0.9、0.95、0.98 | 0.9(扫描下端,更低的没测) | 0.352 | 1 |

T 越大,阈值越像"增益"而不是"开关",所以泄漏开启后不能再放大阈值(T=4 放大到 2 倍,B 起点从 0.25 掉到 0.17)。

| 运行 | A1 | C | C demo | 最后 10 次 5/5 | 整句(贪心 / 束搜索) | 每 token 脉冲 | W2 事件 |
|---|---|---|---|---|---|---|---|
| T=1(基线) | 0.740 | 0.752 | 1/5 | 0 | 0.397 / 0.578 | 1742 | 78 |
| T=2 | 0.832 | 0.825 | 5/5 | 8 | 0.834 / 0.928 | 2996 | 215 |
| T=4 | 0.833 | 0.832 | 5/5 | 6 | 0.912 / 0.969 | 5038 | 494 |
| T=8 | 0.836 | 0.836 | 5/5 | 7 | 0.965 / 0.986 | 9274 | 1565 |
| T=4 只在 q/k/v | 0.776 | 0.783 | 3/5 | 0 | 0.554 / 0.742 | 2654 | 72 |

(种子 0。种子 1、2 见文末第二张表。)

- T=2 已经把 C 从 0.752 拉到 0.825,每 token 脉冲是基线的约 1.7 倍(多 72%);T=4、T=8 再各多一点,逼近浮点的 0.842。
- 多脉冲模型的 5/5 比 T=1 稳得多:最后 10 次里种子 0 是 6–8 次,算上种子 1、2 是 4–9 次(T=2:8、5、5;T=4:6、4、9),T=1 只有 0–1 次。
- T=2/4/8(含 T=2、T=4 的种子 1、2)都满足计划第 7 节的三条软件判据(A1 5/5、C 5/5、C 在 A1 的 1 个百分点内),A1 在 2100–9700 步、C 在 2100–8600 步就按停止规则收敛,而 T=1 跑满 12000 步也没收敛。注意这是改动后的模型(每 token 最多 T 个脉冲)在上面那套放宽的训练预算下通过,不是计划原设定下的验收。
- 种子:T=4 的 C 是 0.832 / 0.835 / 0.836,T=2 的 C 是 0.825 / 0.825 / 0.830,全部 5/5;整句背对率贪心 T=4 0.912–0.946、T=2 0.834–0.887。
- 只在记忆通路 q、k、v 上用 T=4:C 是 0.783(A1 0.776),都没到 5/5,跑满 12000 步,最后仍在升;单种子,分位数(q/k/v 0.9、其余 0.5)也没为这个配置单独扫。即便算上这些,所有点 T=4 在 3100–3800 步就到 0.832/0.833,而只在 q/k/v 用了 3 倍步数仍差约 5 个百分点。所以瓶颈不只在 GDN 的读写地址,q/k/v 之外的脉冲点也限制了精度;这里只比较了这两种配置,没有分出是哪些点。

**硬件代价**:T > 1 意味着每个神经元每 token 最多发 T 个脉冲(时间上 T 个子步,或 T 个脉冲计数)。神经元直接驱动的矩阵乘仍是"每个脉冲一次加法",但 SwiGLU 的门 p = g·u 变成两个计数之积:T = 1 时门只是锁存 + AND,T > 1 时 W2 每通道最多收到 T² 个事件(上表"W2 事件"一列),仍然只做加法,但串行实现时门和 W2 需要最多 T² 个子时隙。电路模型已支持 T > 1,验收结果见"电路模型的 T > 1 支持与验收"一节。

## 方向 3:束搜索

束搜索是批量实现的(`experiments/beam_eval.py`)。K=1 与贪心逐 token 相同:在 29 个前缀上自检,A0 与基线 C 0 处不同;基线 A1 有 11/29 不同,是它的阈值过小导致的数值问题(见其他发现),同一批前缀逐条用束搜索解码时与贪心完全一致。多脉冲和加宽模型没有跑这项自检。排名用长度归一化的对数概率(α=1);α=0 偏向短句,提升打了折扣:T=1 的基线只拿到 α=1 提升的一半左右(A1 50%、C 44%),T=2/4/8 的 C 约四分之三(72–76%)。

| 模型 | 贪心 | K=4, α=1 | K=16, α=1 | K=16, α=0 |
|---|---|---|---|---|
| 浮点 A0 | 0.9997 | 0.9997 | 0.9997 | 0.9997 |
| 基线 A1(T=1) | 0.348 | 0.475 | 0.490 | 0.418 |
| 基线 C(T=1) | 0.397 | 0.556 | 0.578 | 0.476 |
| T=2 的 C | 0.834 | 0.925 | 0.928 | 0.902 |
| T=4 的 C | 0.912 | 0.967 | 0.969 | 0.955 |
| T=8 的 C | 0.965 | 0.986 | 0.986 | 0.981 |

- 束搜索能救回一部分岔路口错误(基线 C +18 个百分点),K=4 已经拿到大部分收益。
- 但它补不了记忆精度:基线 C 加束搜索(0.578)远低于 T=2 的 C 用贪心(0.834)。
- 代价:每 token K 倍的计算,电路上还要存 K 份状态(GDN 的 S 和所有膜电位)。

## 结论与建议

1. 每 token 1 个脉冲是主要瓶颈。把所有脉冲点改成每 token 最多 2 个脉冲(T=2),C 从 0.752 到 0.825–0.830(三个种子),停止时 demo 都是 5/5,而且比 T=1 稳得多(最后 10 次 5/5 的次数见上);整句背对率从 40% 到 83–89%,脉冲是基线的约 1.7 倍。预算允许时用 T=4(0.832–0.836,整句 91–95%)。
2. 训练更久不如 T=2。加宽在 A1 阶段与 T=2 打平,C 落后(0.801 vs 0.825,整句 0.619 vs 0.834),但加宽的 C 没有收敛、只有一个种子;它还要约 2.9 倍的交叉阵列,所以也不如 T=2 划算。
3. 解码用 K=4、长度归一化的束搜索,在 T=2 上把整句背对率从 83–89% 提到 93–95%(三个种子)。
4. 电路模型已支持 T > 1:理想电路对 T = 2、T = 4 与软件逐位相同;标称电路的逐脉冲判据不通过,自由运行时(5 个噪声种子平均)T = 4 只比软件低 1.2 到 1.4 个百分点。详见下一节。

## 电路模型的 T > 1 支持与验收(2026-10-19)

验收脚本是 `experiments/circuit_levels.py`(CPU 单线程)。对照集是 5 句 demo 加按 compare_seed 抽的 200 句。标称电路取计划第 6 节的参数:16 级电导、编程误差 σ_G 2%、读噪声 1%、gain cell 写入与读出误差各 2%、保持因子 0.999、比较器失调为阈值的 2%。失调按量化点给:每块的块入口量化器 cmp1、cmp2 和输出头的量化器各取自己阈值的 2%,符号都为正;同一个量化点的全部通道和 2T 个比较器共用这个值。

"5 个噪声种子"只重新抽样随机误差:电导编程误差 σ_G、读噪声、gain cell 写入与读出误差。电导量化、比较器失调和保持因子是确定的,5 个种子都相同。表里其余标称电路的列是噪声种子 0。T = 1 一行是用这个脚本对同一个 C(`../conversion-sweep/CL2_l1_lif225_lr3e3_12k`)重测的,每次测量都新建电路,读噪声从同一个种子开始。`../conversion-v2-fq50-12k/` 与报告页里的 argmax 一致率 0.625、符号错误率 2.0% / 7.2% / 4.2% / 10.9% 是 `assemble.py` 在同一个电路上先跑自由运行、再跑 teacher forcing 得到的,读噪声的抽样不同;自由运行 acc 0.634、0/5 和 P/R 范围 0.67–0.78 两边相同,5 个噪声种子的 argmax 一致率在 0.608 到 0.644 之间。

- **理想电路与软件逐位相同。** 7 个模型的对照集 logits 最大差都是 0;teacher forcing 逐脉冲对照 P/R 为 1、符号错误率为 0;自由运行的准确率与 5 句结果也和软件相同。计划第 7 节的两项理想电路判据对 T = 2、T = 4 都通过。
- **标称电路的 teacher forcing 判据,7 个模型都不通过。** 判据是 argmax 一致率 ≥ 0.99、每个输出 P/R ≥ 0.9、符号错误率 ≤ 2%;只有状态误差最大值 ≤ 0.1 这一项都通过。
- **自由运行时,多脉冲的退化小得多。** 5 个噪声种子平均下来,标称电路比软件低:T = 1 11.7 个百分点,T = 2 4.8 到 6.5 个,T = 4 1.2 到 1.4 个。5 句全对:T = 4 在 15 次(3 个模型 × 5 个噪声种子)里有 9 次,T = 2 的 15 次与 T = 1 的 5 次一次都没有。同一个模型换噪声种子,准确率的标准差只有 0.0003 到 0.0012;这只反映随机误差的抽样,失调和量化在 5 个种子里固定不变,换一组失调会差多少这里没有测。

### 误差从哪里来

| 去掉电导量化 | 0.647(0/1) | 0.784(0/3) | 0.829(2/3) | 0.638 | 0.803 | 0.930 |

| 去掉读噪声 | 0.632(0/1) | 0.773(0/3) | 0.821(1/3) | 0.613 | 0.810 | 0.910 |

| 去掉状态阵列误差 | 0.635(0/1) | 0.772(0/3) | 0.821(1/3) | 0.620 | 0.802 | 0.906 |

- **T = 1 和 T = 2 时,比较器失调是最大的单项。** 去掉它,T = 1 的标称准确率从 0.634 升到 0.730,T = 2 平均从 0.772 升到 0.818(3 个模型里 2 个 5 句全对);去掉其余任何一项,变化都不到 2 个百分点。
- **T = 4 时每一项单独去掉都不到 1 个百分点,电导量化略大于失调。** 去掉失调从 0.821 升到 0.827,去掉电导量化升到 0.829,3 个模型都是电导量化更大;argmax 一致率分别从 0.903 升到 0.909 与 0.930。电导量化、σ_G、读噪声三项一起去掉,T = 4 到 0.830,argmax 一致率 0.944,是各项里升得最多的。这一行在噪声种子 0 上 3 个模型都 5 句全对,但单个噪声种子上的 5 句全对计数波动很大,不能单独当证据。
- **失调的形式在 T 小时有关系。** 标称设置里同一个量化点的失调是同一个值,整组阈值同向平移。换成每个通道独立随机、标准差相同(同一通道的 2T 个比较器仍共用;只抽了一组,种子 1234),T = 1 和 T = 2 的危害小一些:T = 1 从 0.634 到 0.665,T = 2 平均从 0.772 到 0.788;T = 4 几乎没有差别(0.822 对 0.821)。三种 T 都仍比没有失调差。
- **只让一部分取标称值时(`circuit_tables.md` 第二张表)**,GDN 子块和 FFN 子块(各含自己入口的比较器)单独就能让 T = 2 的最差符号错误率到 9.1% 和 5.3%,状态阵列 3.8%;输出头不影响块内脉冲,只影响 argmax。

- **单步误差。** 单步对照在每个 token 开始前把电路的膜电位、记忆 S 和每块的输入换成软件的,只比这一步(同一步里 GDN 的误差仍会传到同一块的 FFN)。全标称时,单步就已经不过判据:脉冲计数不一致 14%(T = 1)到 35%(T = 4),P/R 0.80 到 0.84,输出头 argmax 一致率 0.76 到 0.96。符号错误率(只在电路与软件都发了脉冲的位置上统计正负相反的比例)却只有 0.3% 到 0.4%,所以正负翻转很少,差别主要是脉冲个数不同:阈值附近的神经元在误差下多发或少发(T = 1 时就是一边发、一边不发)。T 越大,每个神经元的阈值台阶越多,落在台阶附近的神经元也越多。
- **累积。** 普通 teacher forcing 里,不一致的比例在一句话的前 3 个位置是 22% 到 27%,到第 4 到 6 个位置涨到 34% 到 58%,之后只再涨几个百分点;P/R 从单步的 0.80 到 0.84 降到 0.64 到 0.71。跨 token 带着误差的是膜电位(leak 0.9)和记忆 S;残差流每个 token 从嵌入重新开始,只在同一个 token 内把上一块的误差带到下一块。第 26 到 41 个位置的不一致是单步平均值的 1.8 到 2.5 倍;单步的不一致本身也随位置变化,所以这个比值只是粗略的累积量。
- **极小扰动也过不了。** 其余理想、只加 σ_G = 0.0001 的编程误差时,单步几乎完全一致(计数不一致 0.04% 到 0.45%),累积后 P/R 仍降到 0.87 到 0.96,argmax 一致率 0.961 到 0.9899,都低于 0.99;σ_G = 0.001 时三个模型的三项判据都不过。一次只开一种非理想性的扫描里(`circuit_tables.md`),计划标称值的每一项单独开都过不了;扫到的最轻档(256 级电导、σ_G 0.5%、读噪声 0.25%、写入与读出误差 0.5%、失调为阈值的 0.5%)也都过不了,只有 T = 4 的保持因子 0.9999 一档通过(符号错误率 0.8%、P/R 最小 0.91,刚过线)。
- 所以计划第 7 节的逐脉冲判据对模拟误差极其敏感:远小于标称值的误差也会让它不通过。各项误差越大,符号错误率与 P/R 越差(例如 T = 1 电导级数从 256 降到 8,符号错误率从 3.8% 升到 8.5%),所以它能区分误差的大小,只是门槛比计划的标称精度严得多。

### 改了什么

- `step1-spiking-layer/snn_spec/neurons.py`、`circuit.py`、`metrics.py`:脉冲点支持 `levels = T`(LIF、块入口量化器、输出头量化器;比较器为 2T 个;teacher forcing 的 P/R 按脉冲计数统计),算式与 `experiments/multilevel.py` 逐位相同,T = 1 不变。`BehavioralBlock` 的 `crossbar_kw` 可以按矩阵名给出。

### 结论

1. 电路模型支持每 token 多个脉冲:理想电路对 T = 2、T = 4 与软件逐位相同。
2. 标称电路下,计划第 7 节的逐脉冲判据对所有模型都不通过。单步对照就已不过(最差 P/R 0.80 到 0.84,输出头 argmax 一致率 0.76 到 0.96),误差跨 token 累积后更差(P/R 0.64 到 0.71);σ_G = 0.0001 这样的极小扰动累积后也过不了。所以按原阈值,换成单步判据同样不通过;可以换成功能性的判据(自由运行准确率与 5 句全对),或为单步对照另定阈值。改判据由你决定。
3. 按功能看,T 越大电路越稳:标称电路相对软件的准确率损失(5 个噪声种子平均)从 T = 1 的 11.7 个百分点降到 T = 4 的 1.2 到 1.4 个,T = 4 在 15 次里 9 次 5 句全对。
4. T = 1、T = 2 最该先改的是比较器失调:共用的 2% 失调去掉后,T = 2 平均回升 4.6 个百分点,其次是电导量化(1.2 个百分点)。T = 4 时两项都不到 1 个百分点,电导量化(0.8 个)略大于失调(0.6 个)。这些都是把一项完全去掉的结果,只把失调降低一部分时的效果没有测。

## 三值残差流(2026-10-26)

现有模型的残差流 h 是实值累加器(`h + y1`、`h + y2`),每层入口再用 Q_in 读成三值。这里把残差流本身变成三值:嵌入查表后过三值量化器 Q_emb,GDN 直接读三值的 r,`h' = M(r + y1)`,`r_out = M(h' + y2)`,输出头直接读最后一层的 `r_out`;没有 Q_in、q_out 和实值 h。合并 M 把两个三值量相加再压回三值,试了两种:**sat**(饱和加法,阈值 1.0:同号取该号,异号抵消为 0,一路为 0 取另一路)和 **and**(阈值 1.5:只有两路同号才输出 ±1,否则 0)。T=1 时残差严格取 {−1, 0, +1};T=2 时残差沿用脉冲的两级,取 0、±1/2、±1,M 用 2T 个阈值压回。其余沿用 T=2 那几条的配方:A0 权重转移 → 阈值标定 → A1(leak 0)→ B(leak 0.9,LIF 阈值乘一个倍数)→ C,lr 3e-3、上限 12000 步、停止规则不变;fq 在 {0.5, 0.75, 0.9} 里按 iscan 的 teacher forcing 准确率选,LIF 倍数在 {1, 1.5, 2, 2.25, 2.5, 3, 4} 里按 bscan 选。四条链 {sat, and} × {T=1, T=2},种子 0。

代码:`step1-spiking-layer/snn_spec/ternary_residual.py`(`ResidualMerge`、`TernaryResidualBlock`)、`toy_demo/ternary_residual.py`(`TernaryResidualLM`、阈值标定、脉冲计数)、`experiments/ternary_residual.py`(a1 / c / iscan / bscan / chain 子命令)、`experiments/ternres_tables.py`(下面的表与 `ternres_tables.json`)、`run_ternres.sh`(四条链的启动脚本)、`run_ternres_seeds.sh`(种子补跑)。设计与动机见 `docs/superpowers/specs/2026-10-25-ternary-residual-design.md`。

### 结论

1. **精度代价**。T=1:sat 的 C 是 0.625,基线 0.752,低 12.6 个百分点(PPL 4.12 vs 2.58)。T=2:sat 的 C 是 0.811,基线三个种子 0.825 / 0.825 / 0.830,低 1.3–1.9 个百分点(PPL 2.08 vs 1.92–1.96)。T=1 的 A1 和 C 都停在 12000 步上限,最后 1000 步准确率还在涨(A1 0.554 → 0.568,C 0.614 → 0.625),所以 12.6 个百分点里有多少是没训完,这里不知道;只有一个种子。整句背对率把代价放大:T=2 的 sat 贪心 0.706 对基线种子 0 的 0.834(低 12.7 个百分点;基线种子 1、2 的贪心是 0.843、0.887,差得更多),K=4 是 0.795 对 0.903;T=1 的 sat 贪心 0.142 对 0.397,K=4 是 0.178 对 0.483。token 准确率只差 1.3 个百分点,整句就差一成多,三值残差伤的主要是整句记忆。
2. **and 比 sat 差,两个 T 都是**。T=1:0.429 vs 0.625(低 19.6 个百分点);T=2:0.769 vs 0.811(低 4.2 个百分点);整句贪心 T=1 0.032 vs 0.142,T=2 0.486 vs 0.706。and 的 C 还比自己的 A1 低(T=1 0.429 vs 0.451,T=2 0.769 vs 0.788),sat 的 C 比 A1 高(0.625 vs 0.568,0.811 vs 0.804)。原因从规则定义看:and 只在两路同号时才输出,而脉冲是稀疏的(sat、T=2 的 C 里 GDN 输出和 y2 这几个点的非零率是 0.32–0.59),y = 0 时 and 把 r 也清成 0,残差的"恒等通路"被切断;sat 在 y = 0 时 `M(r + 0) = r`,恒等通路保留。这是从定义推的解释,没做消融。胜出规则是 sat。
3. **停止规则**。T=2 的两条都触发了"converged"(sat 9800 步,and 11000 步),但都是最后一次评估碰巧 5/5:最后 10 次评估里只有 1 次 5/5(sat 的 n_exact 序列 4, 4, 2, 2, 4, 3, 3, 2, 4, 5;and 是 3, 3, 4, 3, 4, 3, 2, 3, 2, 5),基线是 8 / 5 / 5。所以停止规则按字面满足,demo 却不稳,比基线差得多。T=1 的两条都没触发,跑满 12000 步,最终 demo 都是 0/5。
4. **脉冲与 W2 事件**(相对基线)。sat:T=1 每 token 1221 个脉冲对 1742(70%),W2 事件 48 对 78(61%);T=2 是 2722 对 3005(91%),W2 187 对 216(86%)。and 反而更多:T=1 1962 个脉冲(基线的 1.13 倍),W2 154(1.97 倍);T=2 3192 个脉冲(1.06 倍),W2 481(2.22 倍)。sat 在 T=1 的省不是白得的,是精度低 12.6 个百分点换来的;and 则是又低又多。
5. **A1 初始化**。权重转移加阈值标定后,sat 的 A1 初始 acc 是 0.051(T=1)、0.113(T=2),基线是 0.123、0.242;and 更低,0.001、0.034。A0 的权重在三值残差下几乎不能直接用,精度几乎全靠 A1 微调补回(sat:T=1 0.051 → 0.568,T=2 0.113 → 0.804)。和基线的差距在 A1 阶段形成(T=1 17.3 个百分点,T=2 2.8 个),C 阶段缩到 12.6 和 1.3 个百分点。B 起点(开 leak、缩放 LIF 阈值)与基线相当(sat 0.211 / 0.265,基线 0.226 / 0.284)。
6. **取舍**。T=2 下 sat 的三值残差代价小(token 1.3–1.9 个百分点),值得继续;T=1 下代价是 12.6 个百分点(且没训完),整句贪心只剩 14%,按现在的结果不够用。只有 T=1 的残差严格是 ±1/0;T=2 的残差是 5 个电平,线上每 token 最多两个脉冲,这是脉冲点本来就有的接口,但"只有三个电平"的说法只对 T=1 成立。

### 电路含义

残差流三值化之后,层间连线和 GDN → 前馈子块之间的连线只传 ±1/0(T=1:2 根线或 2 bit),原来每通道用来累加实值 h 的电容和读出它的 DAC 都不需要了,入口的 Q_in 也没有了;每通道剩下一次三值加法(两路输入相加,和落在 −2..2)加一对比较器(T=2 是 2T = 4 个,阈值 ±j·θ/T),M 的阈值是定死的常数(sat 1.0、and 1.5),不需要标定。嵌入处的 Q_emb 仍在,输出头直接读三值 `r_out`。这是线路结构上的推断,这一变体没有建电路模型,比较器失调、阈值失配对 M 的影响没测。
