01任务和数据

任务是语言模型最基本的一件事：看前面的词，猜下一个词。模型里的“词”叫 token。我们让模型把一小份童话语料背下来，再考它能不能补全原句。

03模型和 GDN

模型只有 116 万个参数：一张嵌入表、两个相同的块、一个输出头。每个块里有一个 GDN 注意力和一个 SwiGLU 前馈。

GDN 是什么

注意力负责让模型记住前文。普通 Transformer 和 GDN 记前文的方式不一样。

04脉冲神经元

脉冲神经网络里，神经元之间传的不是任意实数，而是“发”或“不发”的脉冲。本项目用的是 LIF 神经元。

05转换算法

转换不改网络结构，也不把权重变成二值。它把每个激活点换成脉冲神经元，然后分两步把模型训练回来。

最小算例：跟着算一遍

SNN 版 GDN 一层的流程细节

第 1 步：复制权重，标定阈值

第 2 步：A1 微调，用代理梯度

第 3 步：打开膜电位，B 为什么会塌

第 4 步：C 微调。完整算法

# 输入：训练好的浮点模型 A0、一小部分语料
1  复制  脉冲模型的每个权重 = A0 对应的权重，另加 21 个可学习阈值
2  标定  在前 256 句上、leak = 0，按前向顺序逐点：
      θ = 输入电流（三值点取绝对值）的 50% 分位数，下限 0.001
3  A1    leak = 0，前向用台阶、反向用代理梯度
      同时训练权重和阈值：12000 步，学习率 3e-3 余弦
4  B     把 16 个 LIF 的 leak 改成 0.9，膜电位开始跨 token 携带
5  放大  16 个 LIF 阈值 × 2.25，5 个量化器不动
6  C     leak = 0.9，训练时把膜电位跨 token 的影响也算进梯度
      12000 步，学习率 3e-3 余弦
7  电路  权重写成电导，阈值写进神经元，在电路模型上逐脉冲对照

第 2 步的分位数、第 5 步、A1 和 C 的步数、C 的学习率是这次诊断后改过的；A1 的学习率仍是计划的 3e-3。

07三个改进方向

C 的补全常常在某一个词上走错，然后接上别的句子里背过的片段。我们试了三个方向：训练更久，让每个 token 带更多信息，换一种解码方式。结果是：让每个神经元每个 token 最多发 2 个脉冲，C 就接近了浮点模型。

先看结果

方向一：训练更久

把 A1 或 C 的训练步数翻倍，C 只多了 0.5 到 2.6 个百分点。5 道题还是时对时错，最后 10 次考试里最多只有 1 次全对。训练预算有影响，但不是主要瓶颈。

方向二：每个 token 多给几个脉冲

原来每个神经元每个 token 只有一次机会，只能表达“发”或“不发”。现在把一个 token 分成 T 个小步，神经元最多发 T 个脉冲，发几个就代表多大的值。

只在记忆通路 q、k、v 上用 T = 4，C 跑满 12000 步只到 78.3%，最后还在慢慢上升，而且只跑了一个种子；所有脉冲点都用 T = 2，C 在 7100 到 8600 步就到了 82.5% 以上。所以瓶颈不只在记忆，q、k、v 之外的脉冲点每个 token 能传的信息也不够。这里只比较了这两种配置，还分不出具体是哪些点。

加宽模型

把宽度从 128 加到 256，参数从 116 万变成 297 万。浮点模型本身没有变好，是 84.0%。A1 到了 83.1%，但打开膜电位以后 C 掉到 80.1%，12000 步时还在慢慢上升。它每个 token 的脉冲数和 T = 2 差不多，交叉阵列却要大约 2.9 倍。

方向三：束搜索

贪心解码每一步只留概率最高的那个词。束搜索同时留下 K 条候选句，最后选整句平均每词概率最高的一条。

代价

  • 每个 token 要跑 T 个小步。一个 token 周期里神经元最多发 T 个脉冲。T = 2 时，整个模型每个 token 发出的脉冲约是原来的 1.7 倍，T = 4 和 T = 8 时约 2.9 倍和 5.3 倍。
  • 前馈的门代价涨得最快。门 p = g × u 原来只是锁存加一个与门，现在变成两个脉冲数相乘，后面的 W2 每个通道最多收到 T² 个脉冲，仍然只做加法；串行实现时，门和 W2 要最多 T² 个小步。实测 W2 每个 token 收到的脉冲从 78 个变成 T = 2 的 215 个、T = 4 的 494 个、T = 8 的 1565 个，约 2.8、6.3、20 倍。
  • 电路模型已经跟上。理想电路对 T = 2、T = 4 与软件逐位相同。加上假设的器件误差后，自由运行的准确率（换 5 组随机误差取平均）比软件低：T = 1 11.7 个百分点，T = 2 4.8 到 6.5 个，T = 4 1.2 到 1.4 个。T = 1 和 T = 2 最大的单项误差来源是比较器失调，去掉它准确率回升 9.7 和 4.6 个百分点；T = 4 每一项都不到 1 个百分点，电导量化略大于失调。
  • 束搜索要 K 份状态。束宽 K 就要 K 倍的计算，记忆 S 和所有膜电位也要存 K 份。束宽 4 已经拿到大部分收益。

08结论

  • 转换流程的实现没有错误。代码逐项核对无误；理想电路和软件模型逐脉冲一致；按第 5 节改进后的配方打开跨 token 的膜电位后，C 追上了 A1。第 7 节的配置多数也追得上，但加宽到 256 时 C 比 A1 低 3.0 个百分点，A1 训 24000 步时低 1.8 个百分点。
  • 每个 token 只能发一次脉冲是主要瓶颈。改成每个 token 最多 2 个脉冲，C 从 75.2% 升到 82.5% 到 83.0%，3 个种子都 5 道题全对，整句背对率从 40% 升到 83% 到 89%，脉冲多了约七成。T = 4 时 C 是 83.2% 到 83.6%。训练更久和加宽模型都不如它划算。
  • 刚转换时损失很大，训练能补回大部分。21 个点一起量化，误差层层累积，每个 token 一个脉冲时刚转换只剩一成准确率；第 6 节的提升来自训练更久、C 用更高的学习率、调高 LIF 阈值，脉冲模型从 40.7% 升到 75.2%。第 7 节放宽脉冲上限改的是模型本身：T = 2 到 T = 8 时刚转换就有 24% 到 35%。
  • 还没做到的。标称电路的脉冲级一致性：只看单个 token、误差不跨 token 累积时，脉冲 P/R 也只有 0.80 到 0.84（要求 ≥ 0.9），误差跨 token 累积后降到 0.64 到 0.71。这项判据需要换成功能性的判据，或换成单步判据并重新定阈值。只有 T = 2 和 T = 4 跑了 3 个种子，其余配置都只有一个种子；A1 24k 加 C 24k、加宽的 C、只在 q、k、v 上用 T = 4 的 C 跑满步数时还在上升，再训下去能到多少还不知道。
  • 下一步。T = 2 先处理比较器失调：共用的 2% 失调完全去掉后，T = 2 的标称准确率平均回升 4.6 个百分点，其次是电导量化（1.2 个）；T = 4 去掉电导量化（0.8 个）略多于去掉失调（0.6 个）。只把失调降低一部分时的效果还没测。电路验收的详细结果在 step2-toy-demo/results/improve/README.md。
