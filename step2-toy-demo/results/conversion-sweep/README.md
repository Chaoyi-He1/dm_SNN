# 浮点 → 脉冲转换扫描(2026-09-26)

默认配置(计划第 4–5 节)的三个种子在 A1、C 阶段全部失败后,按第 5 节"三个种子都失败才调整超参数并记录"进行的扫描;**种子重试没有做**:扫描的全部运行都是种子 0(见"对计划文档的记录要求")。诊断见 `diagnostics.md`;每个运行的旋钮、历史与最终评估在 `<run>/result.json`(`experiments/summarize.py` 汇总为 `summary.json`);装配后的完整结果页(含电路阶段)在 `../conversion-v2-fq50-12k/`(本分支的主结果页)与 `../conversion-v2-fq50/`(6000 步对照)。所有数字都在真实切片上用计划的统一评估函数得到;基线 A0:acc 0.8420、ppl 1.794、补全 5/5。本文件的数字、验收表与结论经独立核对(数字全部与 result.json 一致;下文的措辞按核对意见修正)。

## 成本与环境

torch 2.14.0+cu126,NVIDIA RTX A4500(每卡同时跑 4–7 个运行),单线程。A1 6000 步 52–83 分钟(13 个运行,均值 66),12000 步 94–121 分钟;C 4000 步 40–58 分钟,6000 步 48–51 分钟。26 个运行合计约 27 GPU 小时(不含诊断与 CL2)。采纳流水线(L1 + CL1)≈ 2.8 GPU 小时;默认流水线 A1+C ≈ 1.4 小时。装配页 `toy-demo.md` 的"用时"列只是重评估时间,训练时间在 `toy-demo.json` 的 `stages.A1/C.train_seconds`。

## 结论

- **A1(leak 0 微调)最好到 acc 0.746**(fq 0.5、lr 5e-3 + 300 步预热、余弦、12000 步;lr 3e-3 时 0.740),6000 步时 0.698–0.701;默认配置是 0.511。终点评估的补全最多 2/5;训练过程中的评估点最高 4/5(L2 第 11900 步)、3/5(L1),终点都回落到 1/5——5/5 判据在这个精度水平上受评估点噪声支配。
- **C(leak 0.9 微调)最好到 acc 0.682**(CL1:从 12000 步的 A1 出发,训练前只把 16 个 LIF 阈值乘 2.25,lr 3e-3,6000 步),比其 A1(0.740)低 5.8 个百分点;默认配置是 0.407。最好的 C 来自最好的 A1,但在 6000 步 A1 之间不单调:C7 0.663 自 A1 0.677(差 1.4),CF1/CF3 0.649/0.653 自 A1 0.701/0.698(差 4.5–5.2),CF4 0.624 自同一起点加退火;这些对照同时改变了 LIF 倍数(2.5 vs 2.25)、C 步数(4000 vs 6000)与 fq,不能单独归因于 A1 精度。
- **没有一个运行满足第 5 节的平台判据**(5 句全对且最近 500 步提升 <0.1 个百分点):全部因步数上限停止,最后 500 步仍在涨(L1 +0.59、L2 +0.55、R2 +1.19、S1 +0.74、CL1 +0.24、C7 +0.48 个百分点)。A1 与 A0 的差距(0.746 vs 0.842)是否仍受训练预算限制没有定论:没有超过 12000 步的运行。
- **有效的旋钮(同起点对照,单种子)**:A1 步数上限 2000 → 6000(默认 0.511 → R1 0.659,+14.8;两者都是 fq 0.75、lr 3e-3)、6000 → 12000(fq 0.5:+6.3;fq 0.5 + 5e-3 预热:+4.8);C 的 lr 1e-3 → 3e-3(C1 0.516 → C4 0.637,+12.1);C 训练前 LIF 阈值 ×2–2.5(C4 → C7 +2.6,C1 → C6 +3.3);A1 峰值 lr 5e-3 加 300 步预热(S1 − R2 +2.1,PK4w − PK4 +3.1,但 12000 步时 L2 − L1 只有 +0.6);全局分位数 0.75 → 0.5(R2 − R1 +1.8)。
- **单种子下无法分辨的旋钮(≤2 个百分点,而默认运行的种子间差为 0.3)**:fq 0.4/0.5/0.6(0.678/0.677/0.670);按点类型分位数(A1_init 0.104 → 0.182,6000 步后 0.671 vs 全局 0.5 的 0.677);只加预热(−0.3);蒸馏 0.3/T1(−0.1);LIF ×2.25 与 ×2.5;leak 退火(lr 1e-3 时 +2.3,lr 3e-3 时 −2.5)。
- **实测无益或有害**:蒸馏 0.5/T2(R4 − R1 = −2.3;与 T1 的对照同时改了权重与 fq);C 的 lr 5e-3 加预热(CF2 − CF1 = −1.0);最小二乘重拟合、门重拟合、leak 0.9 下重新标定、统一阈值缩放 ≥2、全局分位数 ≤0.4 或 ≥0.7 的 A1_init(见 `diagnostics.md`;fq 0.4 训练 6000 步后与 0.5 持平)。"C 步数 1500 → 4000–6000"没有同起点对照,只是按 A1 的经验外推。
- **电路**:理想电路与 C 逐脉冲一致(argmax 一致率 1.0,状态误差 0,logit 差 0);标称电路自由运行 acc 0.583(C 0.682),σ_G 扫描 0/0.02/0.05/0.10 → 0.582/0.583/0.577/0.560;teacher forcing 对照不通过:argmax 一致率 0.553,各点正负 precision/recall 0.62–0.77(要求 ≥0.9),符号错误率块 0 注意力 2.0%、FFN 6.2%,块 1 注意力 3.7%、FFN 9.8%(上限 2%),状态误差最大值 <0.01(上限 0.1)。不通过的是脉冲级一致性,不是状态阵列。

## 复现

```sh
cd step2-toy-demo
# 主结果页 conversion-v2-fq50-12k(A1 0.740 → C 0.682)
.venv/bin/python experiments/convert_lab.py a1 --name L1_fq50_12k --fq 0.5 --steps 12000
.venv/bin/python experiments/convert_lab.py c  --name CL1 --init results/conversion-sweep/L1_fq50_12k/model.pt --fq 0.5 --steps 6000 --lif-scale 2.25 --lr 3e-3
.venv/bin/python experiments/assemble.py --a1 results/conversion-sweep/L1_fq50_12k/model.pt --c results/conversion-sweep/CL1/model.pt --fq 0.5 --lif-scale 2.25 --out results/conversion-v2-fq50-12k
# 对照页 conversion-v2-fq50(A1 0.677 → C 0.663)
.venv/bin/python experiments/convert_lab.py a1 --name R2_fq50 --fq 0.5 --steps 6000
.venv/bin/python experiments/convert_lab.py c  --name C7 --init results/conversion-sweep/R2_fq50/model.pt --fq 0.5 --steps 4000 --lif-scale 2.5 --lr 3e-3
.venv/bin/python experiments/assemble.py --a1 results/conversion-sweep/R2_fq50/model.pt --c results/conversion-sweep/C7/model.pt --fq 0.5 --lif-scale 2.5 --out results/conversion-v2-fq50
# 最好的 A1(0.746,尚无对应的 C):convert_lab.py a1 --fq 0.5 --lr 5e-3 --warmup 300 --steps 12000
.venv/bin/python experiments/summarize.py results/conversion-sweep      # 汇总表
```

扫描时用 `experiments/run_bg.sh <gpu> <name> <a1|c> [参数]` 后台启动,`experiments/watch_sweep.sh <name>...` 跟踪日志。
