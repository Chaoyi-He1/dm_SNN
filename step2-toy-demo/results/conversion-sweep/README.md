# 浮点 → 脉冲转换扫描(2026-09-26)

默认配置(计划第 4–5 节)的三个种子在 A1、C 阶段全部失败后,按第 5 节"三个种子都失败才调整超参数并记录"进行的扫描。诊断见 `diagnostics.md`;每个运行的旋钮、历史与最终评估在 `<run>/result.json`(`experiments/summarize.py` 汇总为 `summary.json`);装配后的完整结果页(含电路阶段)在 `../conversion-v2-fq50/`。所有数字都在真实切片上用计划的统一评估函数得到;基线 A0:acc 0.8420、ppl 1.794、补全 5/5。

## 结论

- **A1(leak 0 微调)最好到 acc 0.740**(fq 0.5、lr 3e-3 余弦、12000 步),6000 步时 0.698–0.701;默认配置是 0.511。没有任何运行达到 5 句补全全对(最多 2/5,且在相邻评估点之间波动)。
- **C(leak 0.9 微调)最好到 acc 0.663**(从 fq 0.5 的 6000 步 A1 出发,训练前只把 16 个 LIF 阈值乘 2.5,lr 3e-3,4000 步),比 A1 低 1.4 个百分点;默认配置是 0.407。从更高的 A1(0.698–0.701)出发的 C 反而落在 0.639–0.653。
- **有效的旋钮**:A1 步数上限(2000 → 6000:+15 个百分点;→ 12000:再 +6);A1 峰值学习率 5e-3 加 300 步预热(+2);全局分位数 0.75 → 0.5(+2,脉冲密度 ×2)或按点类型只降 Q_in/k/输出头/FFN 内容与输出点(A1_init 0.104 → 0.182,6000 步后与全局 0.5 相当,密度 ×1.5);C 的 lr 1e-3 → 3e-3(+12);C 训练前 LIF 阈值 ×2–2.5(+3–4);C 步数 1500 → 4000–6000。
- **无效或有害的旋钮**:蒸馏(T=2 −2 个百分点;T=1 持平);最小二乘重拟合;门重拟合;leak 0.9 下重新标定;统一阈值缩放 ≥2;全局分位数 ≤0.4 或 ≥0.7;leak 退火(lr 1e-3 时 +2,lr 3e-3 时 −2.5);C 的 lr 5e-3。
- **电路**:理想电路与 C 逐脉冲一致(argmax 一致率 1.0,状态误差 0);标称电路自由运行 acc 0.613(C 0.663),σ_G 扫描 0/0.02/0.05/0.10 → 0.614/0.613/0.606/0.593;teacher forcing 对照不通过(argmax 一致率 0.586,各点正负 precision/recall 0.69–0.75,FFN 符号错误率 4.4%/7.8% 超过 2% 上限,状态误差 <0.01 远在 0.1 之内)。

## 对计划文档的记录要求(第 5 节)

- 第 4 节:发放分位数 0.75 → 0.5(平均发放率 0.234 → 0.457,即脉冲密度 ×2);或按点类型 Q_in、k、输出头、FFN 内容/输出 = 0.5、其余 0.75(密度 ×1.5)。两者 6000 步后的 A1 相当;12000 步的结果只有全局 0.5 做过。
- 第 5 节:A1 上限 2000 → 6000–12000 步;A1 学习率 3e-3 → 5e-3 加 300 步线性预热(可选,+2);C 学习率 1e-3 → 3e-3;C 上限 1500 → 4000–6000 步;C 训练前把 16 个 LIF 阈值乘 2–2.5(B 的定义不变,结果表同时记录未缩放的 B 与缩放后的起点)。
- 考虑过并放弃:蒸馏、最小二乘重拟合、门重拟合、leak 0.9 下重标定、统一阈值缩放、leak 退火(在 lr 3e-3 下)。
- 未解决:5 句补全全对没有达到;A1 与 A0 的差距(0.74 vs 0.84)主要来自每 token 一次二值/三值发放的信息量,而不是训练预算(12000 步的斜率已接近 0);标称电路的符号错误率超限。下一步的候选是规范层面的:更密的编码或每 token 多个脉冲点(超出本计划范围)。
