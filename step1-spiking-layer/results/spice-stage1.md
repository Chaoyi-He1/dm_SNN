# Stage 1 SPICE 测试台结果:2026-09-14

ngspice 47,macOS ARM64。器件参数全部是占位的理想元件或通用模型,不是实测器件;结论针对时序机制和拟合流程,不针对具体器件数值。复现:在 `step1-spiking-layer/` 内执行 `.venv/bin/python -m experiments.spice.gain_cell` 与 `.venv/bin/python -m experiments.spice.dm_neuron`,原始数值见 `spice-gain-cell.json`、`spice-dm-neuron.json`。

## S1.4 单 cell 时序判别

单个 gain cell(1 nF 电容、1 kΩ 泄漏电阻经相位开关接地,τ = 1 µs),采样保持做检索,受控电流源做写入,注入量按规范 S1.4:S₀ = 1,k = e₀,v₀ = 2,q = e₀。四种时序各跑一个周期,测周期末 cell 电压。

| 时序 | 含义 | α=0.5, β=0.5 SPICE | 闭式 | α=0.25, β=1 SPICE | 闭式 |
|---|---|---|---|---|---|
| A | 泄漏窗 → 检索 → 写入(规范) | 1.2502 | 1.25 | 2.0000 | 2.00 |
| B | 检索在泄漏窗之前 | 1.0004 | 1.00 | 1.2504 | 1.25 |
| C | 泄漏窗在写入之后 | 0.7505 | 0.75 | 0.5007 | 0.50 |
| 常开 | 泄漏管整周期导通,周期中点检索并写入 | 0.9681 | 0.970(解析) | 1.0172 | 1.020(解析) |

A、B、C 与闭式的偏差不超过 0.001,判据(与 1.25 偏差 ≤ 0.05、与另两者距离 > 0.15)成立。**发现:** 在原判别点 α = β = 0.5 上,"泄漏常开"给出约 0.97,与形式 B 的 1.00 只差 0.03,单步测试能拒绝它却会把原因误判为"检索顺序反了"。第二判别点 α = 0.25、β = 1 把四者分开(2.00 / 1.25 / 0.50 / 约 1.02),两点都落在 A 上才算时序正确。行为级 `GainCellArray` 用 `leak_before_retrieve`、`retrieve_before_decay` 两个参数复现同样四种情形,数值与 SPICE 一致。

## S1.3 泄漏管的 α 可调区间

存储电容 1 pF,泄漏管为 ngspice level-1 通用 NMOS(vto 0.4 V、kp 2e-5、W/L = 1 µm / 0.5 µm),t_gap = 1 µs,存储值 1 V。ngspice 的 BSIM3 默认模型卡在此偏置下几乎不导通,未采用。

| V_leak (V) | 0.4 | 0.45 | 0.5 | 0.55 | 0.6 | 0.65 | 0.7 |
|---|---|---|---|---|---|---|---|
| α | 1.000 | 0.949 | 0.797 | 0.543 | 0.191 | 0.008 | 0.000 |

V_leak ≤ 0.40 V 时 α = 1,≥ 0.70 V 时 α ≈ 0;α ∈ [0.2, 0.95] 对应的栅压窗口只有约 0.45–0.60 V。**发现:** 同一 V_leak = 0.55 V 下,存储值 1.0 / 0.5 / 0.25 V 的 α 分别为 0.543 / 0.122 / 0.011。MOSFET 在饱和区或亚阈区的泄漏电流与存储电压几乎无关,放电是恒流的、线性的,不是指数衰减,α 不再是与状态无关的乘子。gain cell 的泄漏路径必须做成欧姆型(向 V_mid 放电、小摆幅、三极管区),这一条已写进规范 0.1.2。

## S1.2 神经元的六参数状态模型拟合

占位器件:膜电容 1 nF、泄漏电阻 10 kΩ(τ_m = 10 µs)、带迟滞的阈值开关(V_th = 1.0 V 导通、降到 V_hold = 0.2 V 关断、导通电阻 1 Ω)串 10 Ω;周期 1 µs,每周期注入一个恒定电流,电流取 N(0.3, 0.6²) mA 并截断在 0.75 mA 以下;训练 400 周期,验证 200 周期。

| 参数 | 电路理论值 | 拟合(种子 0 / 1 / 2) |
|---|---|---|
| β_m | 0.9048 | 0.9049 / 0.9049 / 0.9050 |
| g_m (V/mA) | 0.9516 | 0.9513 / 0.9512 / 0.9512 |
| θ (V) | 1.0 | 0.9987 / 0.9994 / 0.9984 |
| U_hold (V) | 0.2 | 0.2241 / 0.2251 / 0.2254 |
| ρ | — | 1.106 / 1.106 / 1.103 |
| n_ref | 0 | 0 / 0 / 0 |

自由运行的拟合模型对 SPICE 发放序列的 precision / recall:种子 0 为 1.00 / 1.00,种子 1 为 0.86 / 0.88,种子 2 为 0.98 / 0.98。S1.2 的门是 ≥ 0.95:三个序列里两个达到,一个没有。差的部分来自复位律用单个 ρ 近似:越阈时刻越早,周期内再充电越多,这个依赖六参数模型表达不了;在 T ≪ τ_m 的线性区它是精确的,这里 T/τ_m = 0.1。

**拟合流程中的三处修正,都是拟合对着 SPICE 才暴露的。** 复位律原写作"回到 U_hold 后部分放电",对这种器件回归会退化(ρ → 1 时 U_hold 不可辨),改为 U ← U_hold·sgn + ρ(U − θ·sgn),ρ = 0 为硬复位、ρ = 1 且 U_hold = 0 即软复位。周期末最后十几纳秒内的发放会把放电拖过周期边界,边界采样落在放电中途,这类离群点让 β_m 偏 2%、θ 偏 30%,改为两遍最小二乘剔除离群点,θ 按分类错误最少选。发放事件按导通的起始边沿计数,不按导通电平。

**两个器件约束,规范"每 token 至多一个脉冲"依赖它们。** 每周期输入电荷必须小于 C_m(θ − U_hold),否则复位后在同一周期内会再次越阈(本例上限 0.8 mA;不截断时 400 周期里有 38 个双发放周期)。导通期间的输入电流必须小于保持电流 U_hold / R_on,否则器件锁定在导通态不再发放(本例 18 mA;R_on = 100 Ω 时只有 2 mA,当时确实观察到锁定)。
