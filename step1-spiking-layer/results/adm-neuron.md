# 真实器件模型:Zhao et al. 2025 的 1M1T1R 扩散忆阻器神经元

2026-09-14。来源:R. Zhao et al., "A spiking artificial neuron based on one diffusive memristor, one transistor and one resistor",
*Nature Electronics* 8, 1211–1221 (2025),补充材料 Supplementary Note 4(物理模型)、Note 6(离散形式)、Table 1/7/8(参数)。
正文在付费墙后,本文只用补充材料里公开的方程与参数表。代码:`snn_spec/adm.py`(Python)、`experiments/spice/adm_spice.py`(ngspice)。

## 模型

扩散忆阻器(Ag/HfO₂ 非对称型,ADM)的导电通道长度 x 分为细丝 x₁ 与残留 x₂(Eq. S1–S4):

- dx₁ = (−γ₁x₁ − βx₁ + μE) dt,dx₂ = (−γ₂x₂ + βx₁) dt
- E = (V_in − V_gs)/(α + |1 − x|)(V_in > V_gs 时,否则 0),x = x₁ + x₂
- R_d = R_on·x + R_off·(e^{(1−x)/λ} − 1)/(e^{1/λ} − 1)
- C_g dV_gs/dt = (V_in − V_gs)/R_d − V_gs/R_c(Eq. S5),输出 O = H(V_gs − V_th)(Eq. S15)

随机项 N₁、N₂ 的方差系数 σ₁、σ₂ 置零就是"理想稳定"版本,本项目用这一版。x 在计算 R_d 时钳到 [0, 1]。

| 参数 | Table 1(与 Fig. 2e 实验匹配) | Table 7(65 nm 能耗估计) | Table 8(3 nm FinFET 快速投影) |
|---|---|---|---|
| μ, α, β | 150, 0.01, 20 | 300, 0.01, 20 | 3×10⁷, 0.01, 2×10⁶ |
| γ₁, γ₂, λ | 600, 5, 0.2 | 600, 5, 0.2 | 6×10⁷, 5×10⁵, 0.2 |
| R_on, R_off | 1 MΩ, 1 TΩ | 1 MΩ, 1 TΩ | 100 MΩ, 4 EΩ |
| C_g, R_c | 10 pF, 250 MΩ | 10 pF, 1 GΩ | 4.14 aF, 242 GΩ |
| V_th(输出阈值) | 0.2 V | 0.2 V | 0.2 V |
| 晶体管 | K = 3.75×10⁻⁴ A/V², V_th 0.22 V,R_l 47 kΩ,V_dd 1 V | R_l 1 GΩ,C_l 1 pF | R_l 242 kΩ,C_l 1 aF |

器件本体:4 µm × 4 µm 的 HfO₂ ADM,R_off 1 TΩ;能耗 1.39 pJ/spike(Table 7 配置);"ADM 可在 100 ns 级工作,可用 10 ns 脉冲刺激、把不应期调到 1 µs"(SI Note 5,属投影)。

## 复现的器件行为(Python,dt = 2 µs,确定性)

发放事件定义为忆阻器导通:x 自下而上越过 1,R_d 塌缩到 R_on。论文的 O = H(V_gs − 0.2 V) 一并计算,但见下文。

| 实验 | 结果 |
|---|---|
| 恒定输入下首次导通时间 | 0.6 V:77.6 ms;0.8 V:34.9 ms;1.0 V:15.4 ms(Fig. 10 用 1 V、25 ms 脉冲测积分时间,量级一致) |
| 0.8 V、2 ms 周期、50% 占空比脉冲串(Fig. 17) | 先积分约 96 个脉冲(首次导通 192.9 ms),之后反复导通;0.4 s 内 523 次导通事件 |
| 泄漏积分(Fig. 19):0.8 V、1 ms 脉冲,间隔 0.2 / 1.0 ms | 首次导通前的脉冲数 50 / 97,随间隔增加 |
| 内在可塑性(Fig. 20):成对 1 V 脉冲 | 间隔 3.5 ms 时第二个脉冲的积分时间由 15.4 ms 缩到 1.0 ms;间隔 180 ms 时由 15.4 ms 缩到 3.9 ms,缩短量随间隔减小 |

**一个对我们的用法有直接影响的现象。** 在 0.8 V、50% 占空比下,残留 x₂ 累积到约 0.77 后每个脉冲都把器件打开、栅电压充到 0.8 V,脉冲间隙 1 ms 只够 V_gs 经 R_c·C_g = 2.5 ms 衰减到约 0.5 V,再也降不到 0.2 V 的输出阈值以下,O = H(V_gs − V_th) 从此恒为 1。所以"每 token 一个脉冲"必须按导通事件计,并且周期与占空比要让 V_gs 在下一 token 前回到阈值以下,或者把 R_c 调小(论文用 R_c 调不应期,50 MΩ 到 1 GΩ)。持续输入下器件在首次导通后进入约 2–3 kHz 的松弛振荡(1 V 恒压 60 ms 内 158 次导通),一个 2 ms 周期内会导通多次,同样违反"至多一个脉冲",输入必须是短脉冲或在导通后撤除。

## ngspice 实现与交叉验证

状态方程用 B 源驱动 1 mF 积分电容实现(电流按 1e-3 缩放,等价于 1 F),R_d 以电导形式给出,晶体管用论文的 level-1 等效(kp = 7.5×10⁻⁴、vto = 0.22 V,R_l 47 kΩ,V_dd 1 V)或 GF180MCU 的 nmos_3p3。

| 恒定 V_in | 首次导通 SPICE / Python | 60 ms 内导通次数(SPICE) | V_gs 的 RMS 差 |
|---|---|---|---|
| 0.6 V | 60 ms 内均未导通 | 0 | — |
| 0.8 V | 34.918 / 34.924 ms | 9 | 0.047 V |
| 1.0 V | 15.428 / 15.432 ms | 158 | 0.065 V |

RMS 差集中在导通瞬间的相位,随 Python 的积分步长减小而收敛(dt = 2 / 1 / 0.5 µs 时 0.065 / 0.053 / 0.040 V),两份实现是同一个模型。脉冲串下 GF180 晶体管版本的栅电压轨迹与论文晶体管版本相同(导通事件 530 对 523,差别来自 ngspice 自适应步长),但沿用 R_l 47 kΩ、V_dd 1 V 时 nmos_3p3(阈值约 0.7 V)的漏端只从 1 V 拉到 0.61 V,论文晶体管拉到 0.05 V;GF180 的输出级要按 3.3 V 工艺重设 R_l、V_dd。

## 六参数状态模型对这个器件不成立

用 S1.2 的拟合流程对 Table 1 物理模型做实验:周期 2 ms,每周期恒定输入电压取自 clamp(N(0.5, 0.3²), 0, 1),16 个神经元、300 周期训练、150 周期验证,发放按导通事件计。

| 状态量 | 种子 0 precision / recall | 种子 1 precision / recall | 拟合出的 β_m, θ |
|---|---|---|---|
| 栅电压 V_gs | 0.00 / 0.00 | 0.00 / 0.00 | 0.42, 0.021 |
| 通道长度 x = x₁ + x₂ | 0.00 / 0.00 | 0.47 / 0.45 | 0.79, 0.881 |

验证集发放率 0.31;周期起始残留 x₂ < 0.5 时发放率 0.11,≥ 0.5 时 0.54。
结论:这个器件的积分量不是栅电压而是离子残留,而且增长是加速的(E ∝ 1/(α + |1 − x|)),线性的"泄漏积分 + 阈值 + 复位"抽象无论取哪个状态量都描述不了它;同一流程对理想阈值开关神经元能到 0.86–1.00。**行为级仿真器里替换 LIF 的应当是物理模型本身(`ADMNeuronModel.step`,状态 (x₁, x₂, V_gs)),不是拟合出的六参数模型。**

## 对计划的影响

1. 器件时间尺度是毫秒到百毫秒(Table 1),token 周期只能是 ms 级;ns–µs 级只有 Table 8 的 3 nm 投影,GF180 上做不到。
2. 每 token 一个脉冲需要短输入脉冲加导通后撤除,或让周期长于 V_gs 回落到阈值以下所需的时间;R_c 是调节旋钮。
3. 神经元的跨 token 状态是 (x₁, x₂, V_gs) 三个量,残留 x₂ 的 200 ms 记忆就是论文的内在可塑性,在折叠 T=1 下它是一条比膜电位更长的记忆通道,软件模型要能表达它。
4. 需要器件组提供的数字:HfO₂ ADM 的阈值/保持电压分布(SI 只有图)、器件到器件差异(Fig. 31,22 个器件),以及是否接受 Table 8 那种快速动力学的假设。
