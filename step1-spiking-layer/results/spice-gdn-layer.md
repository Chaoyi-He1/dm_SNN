# GDN 子块的 SPICE 闭环:2026-10-19

对应 project-plan.md 的 S2.4(首个闭环,给定门值)在 demo 规模上的实现:单头、d = d_k = d_v = 16、16 个 token,
按 S0.7 的相位表在 ngspice 里逐 token 执行,与软件模型 `SpikingGDN`(同权重、同输入、同门值)比对。
代码 `experiments/spice/gdn_layer.py`,测试 `tests/test_spice_gdn_layer.py`,原理图 `schematics/07a–07d`,原始数值 `spice-gdn-layer.json`。

## 电路里什么是真的,什么是理想的

真的(有电容、开关、相位、连续时间):三组投影神经元(q 二值,k、v 三值)、W_O 后的两级三值神经元,每个都是
膜电容 + 泄漏窗(开关串电阻,每 token 泄漏因子 0.9)+ 积分窗 + 比较器 + 脉冲锁存电容 + 减阈值复位电流;
16×16 个 gain cell 电容,泄漏窗长度 t_gap = −ln α_τ·RC 逐 token 变化,行脉冲 × 列 Δv 的写入电流,检索值的采样保持,
β(v − r) 的 delta 块。一个 token 周期 12 µs,16 个相位。

理想的(B 源直接做加法):crossbar 的列求和 Σ_i W_ji x_i、阵列的列求和 Σ_i k_i S_ij 与 Σ_i q_i S_ij。换成电阻阵列与
GF180 开关是下一步。门值 α_τ、β_τ 和块输入 x_τ 由软件记录外部给定(首个闭环的定义)。

S2.4 的四项判据里,这里能测的三项都过:按正负分的 precision/recall ≥ 0.9(实测 ≥ 0.95),符号错误率 ≤ 2%(实测 0),状态误差 ≤ 0.1·界(实测 8×10⁻⁵)。
在环 PPL 需要真实层,不在 demo 规模内。

## 误差来源

状态误差 0.6% 来自泄漏窗长度的时间量化:α = 0.99 对应 t_gap = 14.5 ns,瞬态最大步长 5 ns 时 S 误差 1.2%、o_spk 一致率 0.945;
降到 1 ns 后 S 误差 0.6%、o_spk 一致率 0.992。剩余误差再经阈值放大成个别神经元的翻转,这是连续时间电路对离散软件的固有差异,
规范里用 precision/recall 而不是逐位相等做判据就是为了它。
