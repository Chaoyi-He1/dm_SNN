# 关联检索学习探针

2026-09-13；对应计划 S0.10。结果来自三个预先指定种子 0/1/2，每个训练 1000 步，使用最后一步模型，没有根据留出集挑选模型。

每个 episode 写入 3 个不同 key，各关联 4 类 value 之一，写入顺序取全部 6 种排列；一个空白 token 后，仅给出查询 key，预测对应 value。所有类别及每个查询位置均衡。value 映射按 sum(values)%4 分组：48 种映射训练、16 种映射留出，两者无交集。全部枚举得到 864 个训练 episode、288 个留出 episode；没有新符号，测的是未训练的组合。

模型为 d=16、单头、dk=dv=16 的完整 SpikingBlock，d_ff=32，FIR 关闭；SigmoidGates、alpha 区间 [0.5,0.99]、LIF 阈值 0.3、膜泄漏 0.9、入口可学阈值初始 1。额外连续线性分类头只用于任务读出。Adam lr=0.003、batch=64、裁剪梯度范数 1，CPU 单线程。与延迟复制使用同一脉冲层配置。

## 留出组合结果

| 种子 | 正常状态 | 每步清空全部状态 | 每步清空 S | 每步清空膜电位 |
|---|---|---|---|---|
| 0 | 97.22% | 25.00% | 51.74% | 92.36% |
| 1 | 97.92% | 25.00% | 49.31% | 98.61% |
| 2 | 97.92% | 25.00% | 50.00% | 86.11% |

训练集正确率分别为 99.31%、98.84%、99.07%。按被查询条目的写入位置，留出集正常准确率：seed 0 为 100%/96.88%/94.79%；seed 1、2 为 98.96%/98.96%/95.83%。任务没有仅靠最近写入条目完成。

消融在同一个训练后模型上执行，未重新训练；每步清空 S 消除其跨 token 记忆，仍允许当前步写入。全部清空时，给定查询 key 的标签仍均衡，正确率为 25%。清空 S 后约 49%–52%，相对正常模型下降约 45–49 个百分点，支持该训练配置使用了 S 记忆。清空膜电位后仍有 86%–99%，说明此任务可以主要经 S 完成；消融不能被解释为两种记忆的独立可加贡献。

结论：完成计划中的关联检索可学习性探针，获得正面结果。小规模合成任务不等于真实层语言建模精度验证，也没有覆盖任意容量、长序列或同 key 覆盖写入的学习泛化。没有执行 FLA GPU 或电路仿真。

复现：在 step1-spiking-layer 内执行 `.venv/bin/python experiments/associative_recall.py`。原始日志为 associative-recall.json。数据隔离、查询不含 value、按 query/写入位置的类别均衡均有自动测试。
