# 完整一层的 SPICE 闭环:2026-10-25

在 GDN 子块闭环(`spice-gdn-layer.md`)上补齐前馈子块、两个残差累加器和两组块入口比较器,得到一个完整的 decoder 层:
单头、d = d_k = d_v = 16、d_ff = 32,每 token 最多 T 个脉冲(T = 1、2),16 个 token,按相位表在 ngspice 47 里逐 token 执行,
与软件模型 `SpikingBlock`(同权重、同块输入 h_in、同门值,全部 10 个脉冲点设 `levels = T`)逐脉冲比对。
代码 `experiments/spice/block_layer.py`,测试 `tests/test_spice_block_layer.py`,原理图 `schematics/06`、`08a–08d`,
原始数值 `spice-block-layer-T{1,2}[-seed{1,2}].json`。复现:`.venv/bin/python -m experiments.spice.block_layer <T> ideal 16 <seed>`。

## 电路里有什么

每个 token 依次执行(相位见 `08c`):

1. **load**:16 个累加器电容(1 nF)由 DAC 装入 h_in。
2. **cmp1**:块入口量化器 Q_in1 读累加器,每通道 2T 个比较器(阈值 ±jθ/T,θ = 0.7),结果 x1 采样进 1 pF 锁存。
3. **注意力子块**(与 `gdn_layer` 相同的电路):q/k/v 投影神经元 → 16×16 gain cell 阵列的泄漏窗(t_gap = −ln α·RC)、检索、
   采样保持、delta 写入 → SN_pre → W_O → SN_out,得 y1。
4. **acc1**:y1 的每个脉冲向累加器注入一份电荷(1 个软件单位 = 1 V),得 h_mid。
5. **cmp2**:Q_in2 读 h_mid,锁存 x2。
6. **前馈子块**:W_1 x2 → g 神经元(二值)、W_3 x2 → u 神经元(三值),锁存后 AND 得 p = g·u,W_2 p → y2 神经元(三值)。
7. **acc2**:y2 注入累加器,得 h_out。

**每 token 最多 T 个脉冲。** 每个神经元在积分窗之后有 T 个子时隙。每个子时隙先把比较结果(U ≥ θ/T 为 +1,三值时 U ≤ −θ/T 为 −1)
采样进锁存 f,再让脉冲锁存 s 加 f/T、膜电位减 f·θ/T。T 个子时隙后 s = c/T,c = min(T, ⌊U·T/θ⌋),与 `snn_spec` 的 `levels = T`
逐位相同;T = 1 时就是 `gdn_layer` 的单脉冲神经元。p = g·u 是两个计数之积,取值 c_g·c_u/T²。一个 token 周期 T = 1 时 13.3 µs,
T = 2 时 15.3 µs(五个神经元级各多一对子时隙)。

**真的**(电容、开关、相位、连续时间):全部 10 组神经元、累加器、两组比较器的锁存、gain cell 阵列、检索采样保持、delta 块、AND 前的锁存。
**理想的**(B 源):crossbar 的列求和(`xbar = "ideal"`)、阵列的列求和 Σ_i k_i S_ij 与 Σ_i q_i S_ij、比较器本身、AND 的乘法、DAC。
门值 α、β 是外部给定的每 token 随机值(首个闭环的定义)。`xbar = "R"` / `"1T1R"` 时 7 个权重矩阵都换成 `06` 的差分 crossbar(见末节)。

## 数值上的四处修正

前三处在 4 个 token 的冒烟测试里暴露,第四处在 16 个 token × 3 个种子上才暴露。

1. **记录网格。** `.options interp` 把波形插值到 tran 的 tstep 网格上;tstep = 1 µs 时第 2 个 token 的记录时刻(39.53 µs)被取到
   40.0 µs,已经过了下一个 token 的清零,看起来像电路漏发了 9 个脉冲。改成 0.05 µs 网格,记录时刻离任何相位边沿至少一个网格。
2. **窗口积分。** 按窗口计量电荷的电流(积分、泄漏、复位、计数、累加器注入、gain cell 泄漏与写入)原来用 u(φ − 0.5) 的硬阶跃门控、
   1 ps 边沿;求解步跨过阶跃时窗宽会差半个步长(1 ns 步长下 0.5 ns / 100 ns = 0.5%),第 2 个 token 的 y1 锁存全部是 0.995。
   改为电流直接乘相位电压,相位用 1 ns 线性边沿且 ∫φ dt = 窗宽,边沿两端是求解器必经的断点。h 的误差从 5×10⁻³ 降到 2×10⁻⁴,
   S 从 2×10⁻⁴ 降到 3×10⁻⁵。
3. **积分法。** 采样开关 1 Ω × 1 pF 的时间常数(1 ps)远小于 1 ns 步长,梯形法在这个刚性模态上不衰减,锁存值残留 2×10⁻⁴ 的振铃。
   改用 Gear 后锁存偏差 ≤ 3×10⁻⁵ 级,h 与 S 误差降到 5×10⁻⁶,耗时不变。
4. **相位时刻的舍入。** 相位表原来舍入到 0.1 ns,神经元泄漏窗 −ln 0.9 = 0.1053605 µs 变成 0.1054 µs,泄漏因子 0.899964 而不是 0.9,
   膜电位每 token 差 4×10⁻⁵ 的相对量,|U| 大时累积到 10⁻⁴ 以上。三次运行因此各翻转了一个余量 3.6×10⁻⁵ – 1.8×10⁻⁴ 的判决:

   | 运行 | 翻转的判决(软件余量) | 后果 |
   |---|---|---|
   | T=1 s2 | u₂₇ 第 11 个 token(U = −0.99984) | 该神经元与 p₂₇ 之后 2 个 token、y2 8 个元素不同 |
   | T=2 s0 | y2₁₃ 第 8 个 token(U = 0.50004) | 该神经元之后 5 个元素不同 |
   | T=2 s1 | k₁₂ 第 6 个 token(U = −1.00018) | 写进 gain cell,S 误差升到 6×10⁻²,o_spk、y1、x2、g、u、p、y2 全部开始分歧(最差 P/R 0.939) |

   去掉舍入(相位时刻保留到 0.1 ps,h_in 与权重写 9 位有效数字)后,三处全部判对,上表就是修正后的结果。
   T=2 s1 的情形值得记住:注意力子块里一个 k 的翻转会写进状态,之后所有读状态的输出都受影响,这是 S2.4 不用逐位相等做判据的原因。

## 剩余误差

h_mid / h_out 在三次运行里各有一个元素误差约 10⁻⁴(T=1 s0 与 T=2 s0 都在第 6 个 token 的装载,T=2 s1 在第 14 个 token),
其余元素 ≤ 10⁻⁶。用 1 ns 网格追踪 T=1 s0 第 6 个 token 的那个通道:装载之后 h 与 h_in 相同到 10⁻⁷,误差是 acc1 注入进来的,
y1 = −1 的注入只给了 −0.999915(100 ns 的窗口相当于短了 8.5 ps),锁存的 y1 本身是 −1.000000。这是瞬态求解器在个别窗口里的步长处理造成的;
把 ngspice 的 reltol 从缺省 10⁻³ 收紧到 10⁻⁵ 反而让这个误差增大到 2.4×10⁻⁴、锁存偏差增大到 1.2×10⁻⁴,所以保留缺省容差,没有再往下定位。
10⁻⁴ 对块入口比较器(阈值间距 0.7 / T)不构成风险。

## crossbar 模式

`xbar = "R"`:7 个权重矩阵都是电阻型差分 crossbar(16 级电导、选通是导通电阻 ≈ 790 Ω 的理想开关、每段线电阻 1 Ω),
位线由电流传输器钳在 0 V、电流灌进膜电容;软件参考用同样量化到 16 级的权重。`xbar = "1T1R"` 再把选通开关换成 GF180 nmos_3p3。

首跑(T = 1,4 个 token,修正第 4 处之前的相位表,32 分钟):x1、k 全对,q 在第 1 个 token 错 1 个元素,之后经状态与残差扩散,
第 4 个 token 时 y1 的最差 P/R 0.56、状态误差 / 尺度 0.28,不满足 S2.4。单个 crossbar 的列和误差约 0.4%(`spice-crossbar.json`,
主要是线电阻的 IR drop),比理想求和下的 10⁻⁵ 大两个数量级,余量小于它的判决会翻转;软件参考里没有 IR drop。
用修正后的网表复跑线电阻 1 Ω 与 0 Ω 两种(区分 IR drop 与接线错误)、以及 1T1R 的 2 个 token,结果待补。
